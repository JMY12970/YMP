# YMP — Cracked Script Hub

Welcome to YMP, a small but growing collection of Roblox scripts that have been cracked, cleaned, and deobfuscated so that anyone can read the source and use them without jumping through hoops. Every file in this repository is fully open source, meaning there is no obfuscated blob hiding in the middle of the code, no encrypted string table, and nothing phoning home to a server you cannot inspect. What you see in the repository is exactly what runs when you execute it, so you are free to read through it line by line, learn from it, fork it, trim out the parts you do not want, or improve it and share your own version back.

The most important thing about this hub is that every script here is **key-system free**. None of these files ask you to complete a link shortener, sit through an ad, join a Discord server, solve a captcha, or paste a key into a checker box — the usual walls that script authors put in front of their work have all been stripped out. Each file runs the moment you execute it, straight from the raw URL, with no gatekeeping, no waiting, and no strings attached. There is no "checkpoint" script, no `getkey` function, and no license check to bypass, so you can keep the raw link saved and load it whenever you want without ever touching a browser tab.

It ships with an aimbot that supports FOV-based targeting, smoothness control, prediction and target-part selection, a crosshair, a triggerbot with reaction delay and jitter, and an ESP section with tracers, health bars, names, distance readouts, visibility checks and team filters. It also includes movement tweaks and a full settings tab, so the whole thing is configurable from one menu. Using the hub is deliberately simple: copy either raw link above, wrap it in `loadstring(game:HttpGet(...))()` inside your executor of choice, and press execute — there is nothing else to configure and no key to fetch first. Both scripts are plain, readable Lua, so if you want to understand how a feature works, open the raw URL in a browser tab and read it like any other tutorial file. Fork the repository, change the colors, strip out a module, add your own tab, or rewrite a function from scratch; pull requests and cleaned-up forks are welcome, and nothing here is locked behind a license that stops you from doing it. As with any script from the internet, use it in your own places or where you have permission, keep in mind that third-party executors and exploits can get accounts actioned, and treat everything here as educational reference code that you run at your own risk.
