# YMP — Cracked Script Hub

Welcome to YMP, a collection of Roblox scripts that have been cracked, cleaned, and deobfuscated so that anyone can read the source and use them without jumping through hoops. Every file in this repository is open source, meaning there is no obfuscated blob hiding in the middle of the code, no encrypted string table, and nothing phoning home to a server you cannot inspect. What you see in the repository is exactly what runs when you execute it, so you are free to read it line by line, learn from it, fork it, trim out the parts you do not want, or improve it and share your own version back. The hub currently holds four scripts — two general-purpose menus and two dedicated game builds — and each one is listed below with its own direct raw link. Fork the repository whenever you like, change the colors, strip out a module, add your own tab, or rewrite a function from scratch: nothing here is locked behind a license, and pull requests and cleaned-up forks are always welcome.

The most important thing about this hub is that every script here is **key-system free**. None of these files ask you to complete a link shortener, sit through an ad, join a Discord server, solve a captcha, or paste a key into a checker box — the usual walls that script authors put in front of their work have all been stripped out. Each file runs the moment you execute it, straight from the raw URL: copy a link, wrap it in `loadstring(game:HttpGet(...))()` inside your executor, and press execute, with nothing else to configure. There is no "checkpoint" script, no `getkey` function, and no license check to bypass, so you can keep the raw links saved and load any of them whenever you want without ever touching a browser tab — though as with anything you find on a stranger's repository, read the file before you run it, test it on an account you do not mind losing, and treat it as educational code used at your own risk.
